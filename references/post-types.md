# Telegram Post Types

Select the shortest format that preserves the important evidence.

## FLASH

Target: about 400-700 characters.

Use for:
- urgent database/API/service changes
- concise software releases
- one-result stories with a simple caveat

Must contain: headline/hook, what changed, why it matters, one limitation when needed, source.

## STANDARD

Target: about 900-1500 characters.

Use for most papers, preprints, datasets, and benchmark stories.

Must contain: hook, main evidence, public meaning, important limitation, source.

## DEEP

Target: about 1800-3000 characters.

Use for:
- major benchmark results
- complex AI/biology claims
- stories where methodology changes interpretation
- high-impact infrastructure changes that need actionable detail

Must remain a Telegram post, not become a paper summary. Explain only the technical details needed to understand the significance.
