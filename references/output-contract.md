# Output Contract

Return 2-3 selected Telegram drafts by default unless the user asks for another number.

## Editorial ranking

Before the drafts, give a very short Persian editorial note with:

- selected story rank
- source candidate ID
- post type
- overhype risk

Do not repeat the full Radar analysis.

## Each post

Create one finished, copy-ready Persian Telegram post per story. When the host supports writing blocks, use a separate `social_post` writing block for each distinct story, up to three posts.

Each post should contain, as appropriate:

1. Attractive evidence-safe headline.
2. Short hook.
3. Main verified result or change.
4. Why it matters.
5. Visible limitation/status warning.
6. Source name and durable identifier when useful.
7. Up to 2-4 relevant hashtags when useful.

Do not expose the raw Telegram Handoff JSON unless the user asks for it.

## Review note

After the posts, provide only a compact review note if needed, such as:

- preprint warning retained
- author-reported benchmark retained
- source URL/identifier unavailable in handoff

Do not claim the drafts were published.
